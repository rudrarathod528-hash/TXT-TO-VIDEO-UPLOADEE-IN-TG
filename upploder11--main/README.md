# TXT-TO-VIDEO Uploader Bot

Telegram bot: send a `.txt` file with `Name: URL` lines → bot downloads all
videos (DRM / Appx / YouTube / HLS / direct) and uploads them to your channel.

- ✅ **No MongoDB required** — works fully in-memory
- ✅ No pre-configured credentials — set your own via environment variables
- See the repo-level `README.md` and `.env.example` for setup.
